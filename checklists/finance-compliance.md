# 金融／加密題材合規檢查表

> 外匯、CFD 券商、交易所、穩定幣相關的合作稿與公開發言用。最後一定要用人的眼光照法規讀一遍，不能只看順不順。

## 禁用與替代說法

| 不要寫 / 不要說 | 改成 |
| --- | --- |
| 保證獲利、穩賺、快速致富 | 只描述功能與機制，強調「任何產品都有風險」 |
| 安全、低風險、被動收入 | 說明實際的保護機制（監管、資金隔離），不下「安全」的結論 |
| 「這個值得買／可以布局」 | 「我只談技術與市場觀察，不構成投資建議」 |
| 點名推薦未在台登記的境外平台 | 「建議使用已完成主管機關登記的業者」 |
| 用 USDT 匯款、換匯很方便 | 「代換代匯可能涉及洗錢防制法，請走合規管道」 |
| 用「我們公司認為」講個人判斷 | 「這是我個人的觀察，不代表公司立場」 |

## 客戶合規 brief 常見限制（以實際 brief 為準）

- 特定入金方式不提
- 只寫實際適用的牌照，不放不適用的監管機構 logo
- 不給交易建議
- 教育／品牌內容與「開戶步驟」要有平衡，不能整篇只是註冊教學
