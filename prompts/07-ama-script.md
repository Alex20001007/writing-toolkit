# Prompt｜AMA／X Space／論壇主持講稿

```
我要參加 {{主辦方}} 的 {{X Space／論壇}}，主題是 {{主題}}，長度 {{分鐘}}，題目如下：
{{貼上主辦方給的題目}}

請幫我準備：
1. 依題目分段，每段標預估時間。
2. 每題給「一句話重點」＋「口說稿」（念得出來的口語，不是書面語）。
3. 需要我自己補的資訊用 [方括號] 標出（例：[月瀏覽量]、[入行契機]）。
4. 開頭一張「合規紅線表」：容易講錯的話題 × 不要說 × 改這樣說。
5. 「可以放心引用的事實」清單，每項對照法條原文或官方公告。
6. 結尾「可能的即興追問與安全回法」表。
7. 資料來源。
```

## 自我介紹固定版

> 「大家好，我是 Alex，在動區動趨擔任 Growth Manager，在加密和 AI 領域大約 6 年。現在負責動區的內容、品牌合作與成長，也常在台北主持 DeFi 和機構採用相關的論壇。」

## 常用安全回法

| 被問到 | 回法 |
| --- | --- |
| 推薦哪個平台 | 「我不推薦特定平台，建議選已完成主管機關登記的業者。」 |
| 某代幣值不值得買 | 「我只談技術與生態，不提供投資建議。」 |
| 用穩定幣匯款／換匯 | 「代換代匯可能涉及洗錢防制法，請走合規管道。」 |
| 這場有沒有收錢 | 如實說明活動的合作性質（事前先確認） |
| 其他地區的法規 | 「各地法規不同，請依照你所在地的規定。」不展開 |
| 個人判斷 | 「這是我個人的觀察，不代表公司立場。」 |
