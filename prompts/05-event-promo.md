# Prompt｜活動／社群宣傳文（Hackathon、Meetup、Workshop）

```
幫我寫 {{活動名稱}} 的 X 宣傳文（主辦：{{主辦單位}}，時間地點：{{}}，報名連結：{{}}）。

風格要求：
- 能量感長文，不要一則短推了事。
- 每段用 emoji 當段落標記（🚀 🛠 👥 📍 🎁 之類）。
- 用 Web3 社群語言：BUIDL、組隊、現場開發、Workshop 上手、Demo Day。
- 開頭從「活動本身＋開發體驗」切入。{{獎金池不大時：不要用獎金金額當開頭鉤子，獎金放後段。}}
- 結尾一個號召行動的 CTA（報名連結＋一句集結令）。
- 繁中，專有名詞保留英文。
```

## 段落骨架

1. 🚀 一句話鉤子：這是什麼活動、為什麼你該來
2. 🛠 你會做到什麼（Workshop → 現場開發 → Demo）
3. 👥 適合誰（開發者、設計師、找隊友的人）
4. 📍 時間地點流程
5. 🎁 資源與獎勵（放後面）
6. 👉 CTA：報名連結＋集結令
