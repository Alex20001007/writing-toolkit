# Prompt｜X（Twitter）長文：活動參訪／個人觀點

> 適合：參加大會、參訪、專訪後的第一人稱長文（X Article）。口述框架很亂也沒關係，丟語音轉文字進來即可。

```
我要寫一篇 X 長文（Article），以下是我口述的框架：
{{貼上口述或重點}}

要做到：
1. 先查證文中會提到的背景事實（場館歷史、公司沿革、所有權變動、數字），標出處。
2. 結構：感謝邀請 → 親身體驗（具體感官細節）→ 從體驗延伸到產業觀點 → 背景故事 → 對方的核心觀點 → 收尾＋互動提問。
3. 小標帶情緒與結論，可以引用現場對話當小標。
4. 清單用 emoji 標記（🏛 🥇 🔸 之類），每點一行。
5. 結尾：再次感謝＋一個開放問題引導留言＋2–3 個 hashtag。
6. 給 3 個標題選項。
7. 文末列「發文前請確認」：口述數字和公開報導不一致的地方、名稱差異、規格數字。

不要：把對方口頭給的數字當事實直接寫，要寫成「據 OOO 分享」。
```

## 範例小標（金庫參訪文）

- 一公斤黃金壓在掌心，原來「真實」可以這麼不真實
- 握著金磚的那一刻，我反而更確定 Crypto 為什麼重要
- 「打開門你會覺得平平無奇」：一排貨架，一間就鎖住上百億美元
- 從藝術品避風港到加密巨頭的金庫：Le Freeport 的 16 年
- 葛大的 RWA 哲學：RWA，說到底就是 ReWArd
