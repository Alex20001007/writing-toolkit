# Prompt｜商務寫作：提案、內部說明、合作信、短文案

## A. 媒體合作提案

```
幫我做給 {{客戶}} 的媒體宣傳提案。
1. 先說明 {{客戶}} 目前在 {{市場}} 的狀況與缺口（先做背景調查，標出處；對方自報數字對不上的地方列出來）。
2. 說明為什麼需要下面這些服務才能快速打開市場。
3. 服務項目：{{品項 × 數量 × 單價}}
4. 最後一張表列出所有細項服務，總價 × {{折數}}。
5. 加執行時程與合規承諾。
```

- **報價一定自己再算一次**：品項加總、折扣後金額都要驗算（曾經總價算錯，被客戶留言抓到）。
- 可信度頁需要自家媒體的受眾數據（月瀏覽量、社群追蹤數），沒有就標出待補，不要編。
- 案例佐證：用過去同產業客戶的方案結構（品牌、教育、GEO、行銷活動）與總曝光當 case study。

## B. 給老闆的專案／工具說明

```
幫我寫 {{專案}} 的說明文件給老闆看。結構固定：
1. 概述（最多兩句，不要鋪陳）
2. 問題
3. 解法
4. 功能說明（寫系統做什麼，不寫畫面長怎樣）
5. 目前狀態／優化路線圖
不要寫得很虛。
```

## C. 條件整理／比較文件

- 「簡單容易讀」：摘要表格放最上方，讓老闆掃一眼就懂，細節放後面。
- 條件式收費（什麼情況才收、可議價）寫在表格備註。

## D. 合作申請／商務信

```
幫我寫一封申請 {{合作類型，例如大會 Community Partner}} 的信給 {{對象}}。
說明我們是誰（一句話）、能帶來什麼（受眾、渠道、過去合作）、具體提議、下一步。英文，精簡，一屏內讀完。
```

## E. 社群分享短文案（租屋、徵才、商品等）

- 給兩版：社團分享長版＋限動短版。
- 標題把所有賣點塞進一行（例：附家具、即可入住、可寵、免費車位、可登記）。
