# Prompt｜數據型財經分析文（歷史回測類）

> 範例題目：歷屆聯準會主席換任後，標普 500 的短期走勢。

```
我要寫一篇文章，主題是「{{主題}}」，給 {{媒體}} 的散戶讀者。

1. 先查目前的時事背景（為什麼這個題目現在有人看），再查 3–5 份機構研究，找出主流說法與反駁說法。
2. 用「迷思 vs 真相」當主軸：先講市場流傳的悲觀／樂觀敘事，再用數據拆解它哪裡被誤讀（例：最大回檔 ≠ 點對點累積報酬）。
3. 個別案例各給具體日期與數字，方便排版成資訊圖卡。
4. 自己用原始價格資料算一張表（1／3／6／12 個月點對點報酬＋最大回檔），寫清楚基準日怎麼取，表後寫 3–4 點觀察。
5. 結尾連回當下，不給方向性預測，改給讀者「接下來值得追蹤的 3 個訊號」。
6. 文末列資料來源（機構＋日期）。
7. Markdown 輸出。
```

## 寫法重點

- 數字自己算、程式碼留著可重跑，不從二手文章抄表。
- 表格插在「案例」和「綜合分析」中間；綜合段的文字要跟表的數字對得上。
- 「看起來很弱的平均值」要拆解是不是被單一極端事件拉低。
