# Prompt｜教學文（工具教學／開戶教學）

## A. 工具／開源專案教學

```
幫我寫一篇 {{工具名稱}} 的教學文，給 {{媒體}} 的 {{新手／一般}} 讀者。資料來源：{{GitHub 或官方文件連結}}。

- 先講清楚它「做什麼」和「不做什麼」，再講最基本的安裝與第一次使用。
- 保留「使用情境」段落（3–4 個讀者真的會用到的場景）。
- 進階功能不用寫完，指向 GitHub／官方文件。
- 最後加一段編輯觀點：這個工具背後的策略意圖或產業意義。
- 繁中、全形標點（程式碼區塊內不改）、小標從 H3 開始。
- 輸出 Markdown 原始碼；另附 3 個標題選項與 50 字摘要（三種角度：策略分析／實用工具／趨勢觀察）。
```

## B. 券商／交易所開戶教學（合作稿）

```
參考這篇的結構：{{站內既有開戶教學文連結}}，幫 {{客戶}} 寫一篇開戶教學文。客戶素材：{{合規 brief、活動 PDF、截圖}}。

結構：
1. 品牌可信度（監管牌照、資金保護、獎項、贊助）——通用教育內容只用一句話帶過並連到站內舊文
2. 平台功能（寫深一點）
3. 註冊教學（照實際流程：例如「透過專屬連結網頁註冊 → 再下載 App」，以實測截圖為準）
4. 讀者專屬活動：獎勵上限、門檻、期限、出金條件寫清楚

全程遵守客戶合規 brief（見 checklists/finance-compliance.md）。
文末保留「內部備註」區：列出所有待客戶確認的項目，發稿前刪除。
```

## 截圖處理規格

- 依步驟挑圖，紅框＋編號標註操作位置
- 個人姓名、ID 一律模糊
- 多步驟合成一張多欄圖
- 裁掉手機最上方的狀態列（時間、電量）
- 全部打包成 zip 交付
