## 2026-05｜Fed 主席換任與標普 500

- **定調**：用「迷思 vs 真相」當主軸——先拋出「新主席上任平均回檔 16%」的悲觀敘事，再用「最大回檔 ≠ 點對點報酬」拆解。
- **做法**：五位現代主席各一段案例；自己用每日價格資料算 1／3／6／12 個月報酬與最大回檔表，基準日取上任前最後一個交易日。
- **結尾**：不給方向預測，改給 3 個接下來該追的訊號。
- **學到**：表格放在案例與綜合分析之間；平均值被單一極端事件（黑色星期一）拉低時要拆開講。

## 2026-05｜Spotify CLI 教學

- **修改歷程**：H2 全降成 H3 → 半形改全形標點（程式碼不動）→ 字數砍三分之一 → 補回被砍掉的「使用情境」四點 → 改成新手向，只講做什麼＋基本安裝 → 加一段 Spotify 想成為 AI 語音平台的編輯觀點 → 給標題與 50 字摘要。
- **學到**：精簡可以，但「讀者能拿來做什麼」不能砍；進階內容指向 GitHub；交付 Markdown 原始碼。

## 2026-09｜0G Taipei Hackathon 宣傳

- **學到**：要能量感長文、emoji 段落、BUIDL／組隊／現場開發的社群語言、結尾 CTA；獎金池不大時不要用獎金開場，改從活動與開發體驗切入。

## 2026-09｜交易所 A：鏈上 Meme 交易產品合作稿

- **性質**：軟性置入，大綱與 APP 截圖由客戶提供。
- **結構**：Meme 熱潮回歸與原因 → 兩條新鏈的近期發展 → 簡介同類新型態交易平台（不附截圖）→ 切入產品特色、痛點、福利。
- **決策**：賣點打「鏈覆蓋面＋新鏈接入速度」而不是「首創」；不點名競品交易所；不用宏觀行情開場；不附 FAQ；單一版本 2500–3000 字。
- **小標範例**：「Robinhood 讓 Memecoin 造富神話再現，1 個地址在 7 小時獲利 120 萬美元」。

## 2026-10｜Le Freeport 金庫參訪 X 長文

- **輸入**：一大段語音口述框架。
- **結構**：感謝邀請 → 手捧 1 公斤金磚的體感 → 延伸到「危機時黃金帶不走，Crypto 補上這塊」→ 金庫開門的反差 → 金庫 16 年歷史與易主 → CEO 的 RWA 觀點 → 收尾提問。
- **發文前確認**：口述純度與官方規格不一致；口述保管總額與媒體報導差一個量級（改寫成「據 OOO 分享」）；品牌更名後的稱呼。

## 2026-10｜X Space AMA 講稿（台灣穩定幣）

- **形式**：13 題分段計時、每題一句話重點＋口說稿、[方括號] 標待補資訊、合規紅線表、即興追問安全回法。
- **學到**：初版有兩處法規描述錯誤（發行人資格、法律定性），對照法條原文後更正 → 法規類一律回到條文。

## 2026-10｜AI 交易錢包 C：媒體宣傳提案

- **結構**：市場現況與缺口 → 為什麼需要這些服務 → 服務內容（快訊、廣編、GEO 文、教學文）→ 時程 → 合規承諾 → 細項報價表＋折扣。
- **學到**：總價曾算錯被客戶抓到 → 報價一定驗算；背景調查要列出對方自報數字的矛盾。

## 2026-10｜CFD 平台 B：開戶教學文

- **參考**：站內既有的券商開戶教學文結構。
- **修改歷程**：CFD 基礎教學縮短並連到站內舊文 → 加重品牌可信度（監管、資金保護、獎項、贊助）與平台功能 → 拿掉「台灣用戶」改成「品牌的用戶」→ 獎勵活動機制寫清楚 → 依實測截圖把註冊流程改成「網頁註冊 → 下載 App」。
- **合規**：照客戶 KOL brief（不提加密入金、不用快速／安全／低風險／被動收入等字眼、只寫適用牌照、不寫總部、不給交易建議）。
- **截圖**：紅框編號、模糊個資、合成多欄、裁掉狀態列、打包 zip。
